# Guide administrateur

Connecte-toi avec le second code, puis indique ton prénom et ton nom. Ton identité sera tracée. Un code commun ne prouve pas à lui seul l’identité civile de son utilisateur ; l’historique enregistre l’identité déclarée.

- Consulte les dossiers de l’édition active et les archives en lecture seule.
- Pour corriger un dossier clôturé, crée un avenant avec motif, champ concerné, ancienne valeur, nouvelle valeur et justificatifs facultatifs. Le PDF d’avenant est indépendant. Le document initial n’est jamais réécrit.
- Les codes sont modifiables dans le menu du Sheet. Le changement révoque les sessions existantes ; les brouillons restent sur les appareils.
- Les sessions expirent après six heures. Reconnecte-toi pour renouveler l’accès.
- Ne partage pas la base ni les dossiers photos publiquement. Le partage depuis l’application porte seulement sur les octets du PDF sélectionné.
- Ne modifie pas directement les cellules JSON, les signatures ou les fichiers PDF. Le propriétaire Drive conserve techniquement la capacité de modifier ses fichiers ; l’immutabilité est garantie par les règles de l’application, pas par un stockage WORM.
- Plusieurs brouillons parallèles peuvent exister. Le premier contrôle signé réserve la finalisation ; aucun autre contrôle du même type pour ce véhicule/édition ne peut être signé ou clôturé. Les doublons ne sont pas supprimés automatiquement.

La procédure d’annulation d’un contrôle signé et la clôture globale d’une édition ne sont pas exposées. Elles nécessitent une décision métier ultérieure.
