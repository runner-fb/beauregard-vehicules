# Illustrations véhicules

15 illustrations vectorielles originales créées pour Beauregard Véhicules 2027. Aucun logo ni illustration tierce reproduit. Utilisation, modification et redistribution autorisées pour ce projet.

Chaque fichier utilise le repère `viewBox="0 0 1000 600"`. Les coordonnées des dommages sont normalisées par rapport au rectangle complet : x/1000, y/600. Aucun recadrage ne doit être appliqué après la saisie.

Catégories : `voiture`, `minibus` (9 places), `utilitaire`. Vues : `avant`, `arriere`, `gauche`, `droite`, `interieur`. Les côtés gauche et droit désignent les côtés du véhicule, et non ceux de l'observateur. Illustrations génériques indicatives : les dimensions et équipements du véhicule réel peuvent différer.
